# Solar System UI Component

A modern and responsive React-based solar energy website built as part of my frontend development journey. The project focuses on reusable components, responsive layouts, and clean UI design for a renewable energy company.

## Features

 **Reusable React Components**
  - Built with modular components such as `ServiceCard` and `SkillBar`.
  - Dynamic content passed through React props.

- **Responsive Design**
  - Fully responsive across desktop, tablet, and mobile devices.
  - Uses CSS Flexbox and Grid for layout management.

- **Component-Based Architecture**
  - Organized UI into reusable React components.
  - Separation of components and styling for better maintainability.

- **Service Showcase**
  - Displays solar energy services using reusable service cards.
  - Includes statistics and informative sections.
